HeriTab

Jun to Jul 2026

A passion project: a Chrome extension that shows a different UNESCO World Heritage Site on every new tab. It caches images so pages open quickly, uses a service worker for background loading, and lets people filter more than 1,000 locations by country and image quality.

View on the Chrome Web Store

JavaScript, Chrome extension APIs

Screenshots

What it does

  • Shows a different UNESCO World Heritage Site on every new tab.
  • Caches images so new tabs open quickly.
  • Uses a service worker to load the next images in the background.
  • Lets people filter more than 1,000 locations by country and image quality.
